# Canonical-generator executable subset

This directory records 15 pairs regenerated by the released canonical
implementation in `src/rag_da.py`. The build uses `max_ids=1`, seed `42`, and
strict AST mode (`allow_lexical_fallback=false`). It therefore complements the
separate frozen historical subset with an implementation-linked check.

Regenerate the pairs from the reviewed clean snippets:

```powershell
python build_canonical_generator_subset.py
```

Compile and execute the regenerated pairs:

```powershell
python ../executable_spotcheck/run_spotchecks.py `
  --subset canonical_generator_pairs.jsonl `
  --sources-dir canonical_sources `
  --build-dir canonical_build `
  --results-json canonical_spotcheck_results.json `
  --results-md canonical_spotcheck_results.md
```

The spot check covers the concrete generated pairs only. It is not a proof of
whole-project equivalence or of every possible generator output.
